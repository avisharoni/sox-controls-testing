# sox-controls-testing

Tools for common SOX / internal audit analytics. **All data is synthetic**, generated by `soxct/synthetic.py`; it does not represent any real company.

- `sampling.py` – attribute sample size (zero/low expected deviation, binomial confidence) and reproducible random selection; deviation-rate evaluation.
- `je_anomaly.py` – journal-entry tests: weekend/after-hours postings, round amounts, entries just below an approval threshold, manual entries by unusual users, Benford first-digit deviation.
- `sod.py` – segregation-of-duties conflicts from a user-to-permission matrix against a rule set.

```bash
pip install -r requirements.txt
python -m soxct.demo
pytest -q
```
